1- Create database 

>> CREATE DATABASE school;


2- show table 

SHOW TABLES FROM school;

3- CREATE table 

Go to the database that we want to create table 

>> mysql> SHOW TABLES;

+------------------+
| Tables_in_school |
+------------------+
| students         |
+------------------+


>> USE school

>> CREATE TABLE students(
    -> id INT AUTO_INCREMENT PRIMARY KEY,
    -> name VARCHAR(255),
    -> course VARCHAR(255),
    -> mobile VARCHAR(255));

4- insert data to the table

>> INSERT INTO students (name,course,mobile)
    -> VALUES ("Vibol Long","Math","12345");



5- See the row in the table 


>> SELECT * FROM students;
