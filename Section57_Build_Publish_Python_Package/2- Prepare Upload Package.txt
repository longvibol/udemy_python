Prepare Upload Package : 

1- Create file setup 

setup.py 


from setuptools import setup


----------------------------------------------------------------------------------------------------------------

setup(
  name = 'invoicing-fdp',         #* Your package will have this name
  packages = ['invoicing'],   #* Name the package again
  version = '1.0.0',         #* To be increased every time your change your library
  license='MIT',             # Type of license. More here: https://help.github.com/articles/licensing-a-repository

  keywords = ['vibol','invoice', 'excel', 'pdf'],   # Keywords users can search on pypi.org

  classifiers=[
    'Development Status :: 3 - Alpha',          # Chose either "3 - Alpha", "4 - Beta" or "5 - Production/Stable" as the current state of your package
    'Intended Audience :: Developers',          # Who is the audience for your library?

  ],

----------------------------------------------------------------------------------------------------------------

1) Install build tools


>> python -m pip install --upgrade pip setuptools wheel build twine

python -m build


2) Build the package (recommended)

>> python -m build

This creates:

dist/*.tar.gz (source distribution)

dist/*.whl (wheel)

3) Check the build

python -m twine check dist/*


4) Upload to PyPI (or TestPyPI first)


python -m twine upload --repository testpypi dist/*


5- Real PyPI:


python -m twine upload dist/*
