enumerate : function we can convert to the list that have [ index and value ] 

Function find similar movie with title : 

def similar_movies(movie_title, nr_movies):
    idx = movies.loc[movies["title"] == movie_titile].index[0]
    scores = list(enumerate(similarity_matrix[idx]))
    scores = sorted(scores, key= lambda x : x[1], reverse=True)
    movie_indices = [tpl[0] for tpl in scores[1:nr_movies+1]]
    similar_titiles = list(movies["title"].iloc[movie_indices])
    return similar_titiles
