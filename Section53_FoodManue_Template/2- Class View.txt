1- In the app : restaurant menu - template with class view 

1.1- create views.py 

- we use the class template 

from django.views import generic
from .models import Item

class MenuList(generic.ListView):
    queryset = Item.objects.order_by("-date_created")
    template_name = "index.html"

class MenuItemDetail(generic.DetailView):
    model = Item
    template_name = "menu_item_detail.html"


---------------------

Explain :
- queryset : it take the model from the database 
- template_name : where we give our template (hmtl )

They are the predefine from the generic.ListView in the Django 

Note: but if we use Function view, it need the render 


1.2- create urls.py (route)


from django.urls import path
from . import views

urlpatterns = [
    path('', views.MenuList.as_view(), name='menu')
]


Note: views.MenuList.as_view() : as_view is what we use for the class template view
